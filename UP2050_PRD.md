## 1. Executive Summary

> *A bold, data-driven visual experience that shows Uttar Pradesh not as it is remembered, but as it will be — India's most transformed state by 2050.*

**UP 2050** is a hackathon submission for the Hack2Skill × Google for Developers *"Which State Am I?"* Mini Challenge 2. The product is an interactive digital poster / micro web experience that encodes Uttar Pradesh's identity through the lens of its 2050 future — **without naming the state once.**

Built entirely in Python (Matplotlib + GeoPandas + Flask). The poster is generated as a static PNG via CLI and served via a Flask web app deployed on Render.

## 5. Non-Functional Requirements

### 5.1 Visual Quality

- Final PNG minimum resolution: **1080×1080px** (generated at 216 dpi for 2× quality)
- Color palette: defined in `utils/palette.py` — Deep Saffron `#FF6B00`, Ganga Blue `#1A6B8A`, Gold `#FFD700`, Charcoal `#1A1A2E`
- Font: Space Grotesk + Tiro Devanagari Hindi registered in Matplotlib
- No stock-photo feel — all visuals are Python-generated vector paths

### 5.2 Social Media Compliance

- No state name in image, caption, or alt text
- Tags placed correctly on platform
- Hashtag `#WhichStateAmI` present
- Post set to **Public** visibility
- Link submitted to Hack2Skill portal before deadline

### 5.3 Performance (Web Version)

- Flask app loads in under **3 seconds** on mobile 4G (serves pre-generated static PNG)
- Works on Chrome, Safari, Firefox
- Mobile responsive — **375px minimum viewport** via CSS

### 5.4 Python Environment

- Python 3.11+
- All dependencies in `requirements.txt`
- `python generate_poster.py` produces output in under **10 seconds** on standard hardware
- No runtime API calls — all data is static JSON/CSV
